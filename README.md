 Домашнее задание к занятию "Репликация и масштабирование. Часть 1" - `Петрикин Дмитрий`

Задание 1
На лекции рассматривались режимы репликации master-slave, master-master, опишите их различия.

Ответить в свободной форме.

Master-Slave

Пишут только в один сервер (master)
Остальные (slave) - только для чтения
Репликация в одну сторону
Конфликты почти невозможны
Самый простой и надёжный вариант
Используется в 95%+ случаев

Master-Master

Писать можно в любой сервер
Репликация двунаправленная
Очень легко получить конфликты (одна строка изменена в двух местах)
Сложно, требует осторожности, автоинкременты и последовательности - отдельная боль
Используется редко

Коротко:
Master-Slave - для большинства реальных задач.
Master-Master - только если очень нужно писать одновременно в несколько мест и вы готовы к головной боли.
В большинстве случаев лучше взять Group Replication / Galera / распределённые БД, чем классический master-master.
